# Agent Workflows

## Implementation
1. Read AGENTS.md.
2. Read relevant docs.
3. Make minimal scoped changes.
4. Validate the completed work unit.
5. After validation passes, create a focused Git commit for that independently completed work unit.
6. Handoff only after the commit is created, unless the user/task explicitly says not to commit.

Commit rules:
- Keep each commit scoped to one independently completed work unit.
- Do not mix unrelated changes into the commit.
- Do not commit failing or unfinished work unless an explicit checkpoint commit is requested.
- Do not amend, squash, or rewrite existing commits unless explicitly requested.

## Review
- Check architecture boundaries.
- Check package ownership.
- Check documentation updates.
